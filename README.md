# 📊 E-Commerce Sales & Customer Insights Dashboard

## 🚀 Project Overview

This project presents an end-to-end data analytics workflow, transforming raw e-commerce data into actionable business insights. The analysis focuses on understanding sales performance, customer behavior, and payment trends using Python, SQL, and Power BI.

---

## 🛠️ Tech Stack

* **Python** (Pandas, NumPy) – Data cleaning & preprocessing
* **SQL (SQLite)** – Data querying & analysis
* **Power BI** – Interactive dashboard & visualization

---

## 📂 Dataset

* Real-world e-commerce dataset (~100K+ records)
* Includes:

  * Orders
  * Customers
  * Payments
  * Order items

---

## 📊 Key Features

* Data cleaning and merging from multiple sources
* SQL-based analysis for business queries
* Interactive Power BI dashboard
* KPI-driven insights for decision making

---

## 📈 Dashboard Highlights

* 💰 **Total Revenue Analysis**
* 📦 **Total Orders & Average Order Value**
* 📊 **Revenue Trends Over Time**
* 💳 **Payment Method Distribution**
* 🌍 **Top Cities Driving Revenue**
* 👥 **Customer Behavior Insights**

---

## 🔍 Key Business Insights

* Credit cards contribute the majority of total revenue, indicating strong digital payment adoption.
* A large proportion of customers are one-time buyers, highlighting low customer retention.
* Revenue is concentrated in a few major cities, suggesting geographic dependency.
* Sales show variation across months, indicating potential seasonal trends.
